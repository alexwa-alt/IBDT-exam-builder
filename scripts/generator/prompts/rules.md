# Question-writing rules (all mandatory)

### 5.1 Paper structure
- SL Paper 2 = **50 marks in 1 h 30 min**: five 6-mark questions then two 10-mark questions.
- Each question stands alone: a short **case study (stimulus)** with figures/tables/data, then parts (a), (b), (c)…
- Each question is **exactly 6 or 10 marks**. Each part is **at most [4]**. Parts sum exactly to the total.
- 6-mark patterns: **1+2+3** (State/Identify → Outline/Describe → Explain/Evaluate) or **1+1+2+2**.
- 10-mark patterns: **2+2+2+4** or **1+2+3+4**, last part a 4-mark **Evaluate, Analyse or Justify**.
- Early parts recall/understanding; later parts application and judgement.

### 5.2 Command terms
The command term is the **first word of the question**, or the word after the first comma in
"Using Figure 1, outline…". Allowed terms with usual marks:

| Term | Marks | AO | Meaning in practice |
|---|---|---|---|
| State | 1 (2) | AO1 | |
| List | 1, 2 | AO1 | |
| Label | 1, 2 | AO1 | |
| Identify | 1, 2 | AO2 | |
| Outline | 2 | AO2 | feature + short impact |
| Describe | 2, 3 | AO2 | |
| Demonstrate | 2, 3 | AO2 | with a real product example |
| Apply | 2, 3, 4 | AO2 | |
| Present | 2 | AO2 | (from specimen) |
| Explain | 3 (4) | AO3 | feature → mechanism → outcome |
| Analyse | 3, 4 | AO3 | trade-offs |
| Evaluate | 4 (3–6) | AO3 | strengths + limitations + supported verdict |
| Justify | 3, 4 | AO3 | |
| Design | 3–6 | AO3 | |

Other mark values only produce a warning. **Never** use "Discuss", "Determine" or any unlisted term.
Wording must match command term and marks ("Outline two…" only for [2]).

### 5.3 Syllabus statements (SL only)
Every part lists the statement ids it assesses, e.g. `[A1.1.3, B1.1.2]`. Valid SL ids:

`A1.1.1–7, A2.1.1–5, A2.2.1–6, A3.1.1–9, B1.1.1–5, B2.1.1–15, B2.2.1–6, B3.1.1–4, C1.1.1–3,
C1.2.1–3, C2.1.1–4, C2.2.1–5, C3.1.1–7`

Anything else (including HL ids) is rejected. Take the statement wording from `DT_IB_Strands.xlsx` and
check that each part genuinely assesses the statements it cites.

### 5.4 Banned words
Matched at the **start of any word, anywhere** in the file (stimulus, answers, notes): e.g. *leverage*,
*inventory*, *gearbox* all fail.

- **HL-only:** gear, lever, pulley, linkage, cam follower, young's modulus, safety factor, factor of
  safety, four-pleasure, attract/converse, act model, life-cycle analysis, life cycle analysis,
  cradle-to-grave, injection mould, blow mould, rotational mould, extrusion, casting, production system,
  mass production, batch production, design for assembly, design for manufacture, design for process,
  op-amp, microcontroller, transistor, cantilever, stress-strain, yield strength, internet of things,
  4d print, welding, welded
- **Old syllabus:** rogers, product champion, entrepreneur, inventor, sustaining innovation, disruptive,
  process innovation, end-of-pipe, converging technolog, conceptual model, instrumented model,
  eco-design, maturity, green legislation, design for materials, technology push, market pull,
  eco-label, radical innovation, incremental innovation, dominant design, ashby, poka-yoke

Past-paper case studies often contain these words (they come from the old syllabus). **Rewrite the
case-study text** to avoid them.

### 5.6 Stimulus and style
- Base on a past-paper case study (§4). Keep the real product facts; add a **data table** where it
  enables data-based parts. If data are invented or approximated, end the stimulus with a `note`
  block: "Data written for this practice paper." (or "…(approximate values).").
- Stimulus text about **120–250 words (6-mark)** or **200–350 words (10-mark)**, plus 1–2 figures/tables
  (10-mark questions may use up to 3).
- Neutral, precise, short sentences, like the specimen.
- Every part is about the case study, not pure recall. Every answer must be supportable from the
  stimulus plus SL syllabus knowledge.
- Figures and tables are numbered from 1 **within each question** and every one must be referred to by
  number in a part. Don't number the question; don't draw answer lines (the build adds them).
- Difficulty: 1 foundation, 2 standard, **3 challenging = unfamiliar context, data interpretation or
  calculation, sustained judgement**.

### 5.7 Markscheme conventions (from the specimen)
- `answers`: one ✓ marking point per item, **more points than marks**; use " / " for alternative wording.
- `notes`: how to award, e.g. "Award [1] for each relevant point up to [2 max]."
- For 3–4 mark Explain/Analyse/Evaluate/Justify, notes must say **what full marks need** (e.g. "To gain
  [4] the response must include strengths and limitations, use data from Table 1 and reach a supported
  judgment. Award [3 max] if there is no judgment and [2 max] for a one-sided response.").
- Evaluate answers give `<b>Strength:</b>` / `<b>Limitation:</b>` points (optionally tagged by
  people/planet/profit etc.) and an example `<b>Conclusion:</b>`; accept a well-supported judgement either way.
- **Extra pass:** look for alternative scientifically/technically valid answers and add them, so
  students aren't penalised for correct answers phrased differently.
